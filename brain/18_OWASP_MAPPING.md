# 18 — OWASP Security Verification & Compliance Mapping

This document provides a comprehensive mapping of the **SenseAI Voice Assistant** against the **OWASP Top 10 Web Application Security Risks (2021)** and the **OWASP Top 10 for Large Language Models (2025)**.

---

## 1. OWASP Top 10 Web Application Security Risks (2021)

| OWASP Web Risk | Vulnerability Description | SenseAI Mitigation & Controls | Implementation References |
| :--- | :--- | :--- | :--- |
| **A01:2021 Broken Access Control** | Unauthorized access to internal endpoints, administrative functions, or cross-tenant session state. | - Strict HS256 JWT validation on WebSocket/WebTransport handshakes with session scoping.<br>- Localhost-only binding (`127.0.0.1`) prevents unauthenticated LAN/WAN access.<br>- MCP server is strictly read-only with zero administrative mutation capabilities. | [`src/backend/security/auth.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/auth.py)<br>[`src/backend/mcp_server/server.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/mcp_server/server.py) |
| **A02:2021 Cryptographic Failures** | Sensitive data transmitted in cleartext or stored without encryption. | - Transport encryption: Strict `wss://` TLS 1.3 and native HTTP/3 QUIC encryption.<br>- At rest: Field-level AES-128-CBC (Fernet) encryption of spoken transcripts and emotion records.<br>- Zero persistence for raw ingested voice audio. | [`src/backend/database/storage.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/database/storage.py)<br>[`config/production/.env.example`](file:///d:/Capstone%20Project/NewSenseVoice/config/production/.env.example) |
| **A03:2021 Injection** | Command injection, SQL injection, or path traversal via untrusted user inputs. | - Parameterized SQLite queries prevents SQL injection.<br>- Path traversal defense in document ingestion using `os.path.realpath` canonical validation.<br>- Deterministic command routing with strict `COMMAND_WHITELIST` sandboxing. | [`src/backend/database/storage.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/database/storage.py)<br>[`scripts/database/build_rag_index.py`](file:///d:/Capstone%20Project/NewSenseVoice/scripts/database/build_rag_index.py)<br>[`src/backend/pipeline/intent.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/pipeline/intent.py) |
| **A04:2021 Insecure Design** | Architectural flaws lacking defense-in-depth and threat modeling. | - Formally documented STRIDE threat model across 6 attack surfaces.<br>- Multi-gate intent routing: RAG and commands are explicit gates, never default.<br>- Circuit breakers and GPU concurrency limiters protect shared model resources. | [`brain/10_SECURITY.md`](file:///d:/Capstone%20Project/NewSenseVoice/brain/10_SECURITY.md)<br>[`src/backend/resilience/circuit_breaker.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/resilience/circuit_breaker.py)<br>[`src/backend/resilience/gpu_limiter.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/resilience/gpu_limiter.py) |
| **A05:2021 Security Misconfiguration** | Unhardened defaults, unnecessary features enabled, permissive CORS, or missing security headers. | - Explicit CORS whitelist limited to `127.0.0.1:5173`.<br>- All secrets externalized to `.env`; templates sanitized in `security/secrets.example/`.<br>- Automated CI verification checks for exposed secrets and high-risk packages. | [`.github/workflows/ci.yml`](file:///d:/Capstone%20Project/NewSenseVoice/.github/workflows/ci.yml)<br>[`security/security-checklist.md`](file:///d:/Capstone%20Project/NewSenseVoice/security/security-checklist.md) |
| **A06:2021 Vulnerable and Outdated Components** | Supply chain vulnerabilities in third-party Python/Node libraries. | - Automated CI jobs running `pip-audit` against Python dependencies and `npm audit --audit-level=high` against frontend packages.<br>- Pinned versions and security updates tracked in changelog. | [`.github/workflows/ci.yml`](file:///d:/Capstone%20Project/NewSenseVoice/.github/workflows/ci.yml)<br>[`src/backend/requirements.txt`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/requirements.txt) |
| **A07:2021 Identification and Authentication Failures** | Weak password policies, unvalidated session tokens, or replayable tokens. | - Cryptographic HS256 tokens with configurable `SESSION_TIMEOUT_MINUTES`.<br>- Constant-time HMAC comparison prevents timing attacks.<br>- Algorithm locking forbids `alg: none` downgrades. | [`src/backend/security/auth.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/auth.py) |
| **A08:2021 Software and Data Integrity Failures** | Tampering with application code, serialized data, or logging integrity. | - Append-only, SHA-256 hash-chained audit ledger (`logs/audit.log`) detects any retroactive log tampering.<br>- Magic byte inspection verifies uploaded file integrity before parsing. | [`src/backend/security/audit.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/audit.py)<br>[`scripts/database/build_rag_index.py`](file:///d:/Capstone%20Project/NewSenseVoice/scripts/database/build_rag_index.py) |
| **A09:2021 Security Logging and Monitoring Failures** | Unlogged authentication failures, silent command execution, or unmonitored anomalies. | - Dedicated cryptographic audit logger records all authentication successes, rejections, and command attempts.<br>- Automated operational health audit checks system health endpoints. | [`src/backend/security/audit.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/audit.py)<br>[`monitoring/health-checks/check_health.py`](file:///d:/Capstone%20Project/NewSenseVoice/monitoring/health-checks/check_health.py) |

## 2. OWASP Top 10 for Large Language Models (2025)

| OWASP LLM Risk | LLM Threat Description | SenseAI Mitigation & Controls | Implementation References |
| :--- | :--- | :--- | :--- |
| **LLM01: Prompt Injection** | Adversarial user prompts manipulate LLM behavior, override instructions, or jailbreak safety bounds. | - Inbound sanitization (`sanitize_transcript`) neutralizes override markers (`system:`, `[INST]`, `<<SYS>>`).<br>- Strict prompt delimiter isolation framing user inputs.<br>- Outbound filter (`filter_llm_output`) blocks sensitive leakage. | [`src/backend/llm/prompts.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/llm/prompts.py)<br>[`tests/unit/test_prompt_injection.py`](file:///d:/Capstone%20Project/NewSenseVoice/tests/unit/test_prompt_injection.py) |
| **LLM02: Sensitive Information Disclosure** | Model inadvertently emits internal system prompts, configuration secrets, or private session history. | - Outbound regex filtering (`filter_llm_output`) scans generated tokens for system prompt patterns, API keys, and credential formats, replacing them with generic fallback responses. | [`src/backend/llm/prompts.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/llm/prompts.py) |
| **LLM03: Supply Chain Vulnerabilities** | Compromised model weights, fine-tunes, or AI frameworks. | - Fixed model IDs pinned to authoritative repositories (`iic/SenseVoiceSmall`, `ai4bharat/*`, `Qwen3`).<br>- Offline quantized GGUF execution eliminates unverified runtime weight downloads. | [`src/backend/config.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/config.py)<br>[`docs/DEPLOYMENT.md`](file:///d:/Capstone%20Project/NewSenseVoice/docs/DEPLOYMENT.md) |
| **LLM04: Data and Model Poisoning** | Adversary pollutes RAG documents to corrupt vector index retrieval and poison model responses. | - Multi-stage document validation inspecting extensions, magic bytes, and file size limits.<br>- Vector index is segregated in `data/index/` and derived solely from validated admin documents in `data/documents/`. | [`scripts/database/build_rag_index.py`](file:///d:/Capstone%20Project/NewSenseVoice/scripts/database/build_rag_index.py)<br>[`src/backend/rag/retriever.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/rag/retriever.py) |
| **LLM05: Improper Output Handling** | Downstream consumers execute unvalidated LLM output as raw code, HTML, or SQL commands. | - LLM output is strictly treated as conversational text.<br>- Sentence chunker partitions text solely for Parler-TTS audio synthesis; no dynamic `eval()`, shell execution, or DB execution from model tokens. | [`src/backend/llm/sentence_chunker.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/llm/sentence_chunker.py)<br>[`src/backend/pipeline/orchestrator.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/pipeline/orchestrator.py) |
| **LLM06: Excessive Agency** | Granting LLMs autonomous capabilities to execute destructive tools without verification. | - The LLM has zero direct tool execution authority.<br>- Commands are routed deterministically ahead of the LLM via `IntentRouter`, sandboxed by `COMMAND_WHITELIST`, and logged to the audit ledger. | [`src/backend/pipeline/intent.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/pipeline/intent.py)<br>[`src/backend/security/audit.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/audit.py) |
| **LLM07: System Prompt Leakage** | Extraction of proprietary prompt instructions defining assistant persona and safety constraints. | - `filter_llm_output()` explicitly inspects and suppresses attempts to parrot back prompt conditioning instructions or internal state labels. | [`src/backend/llm/prompts.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/llm/prompts.py) |
| **LLM08: Vector and Embedding Weaknesses** | Exploiting dense retrieval to inject adversarial context or execute semantic extraction. | - Dense vector search strictly queries local FAISS indices with cosine/inner-product similarity.<br>- Intent router treats RAG as a guarded gate; missing indices gracefully degrade to general chat without leaking embeddings. | [`src/backend/rag/retriever.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/rag/retriever.py)<br>[`src/backend/pipeline/intent.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/pipeline/intent.py) |
| **LLM09: Misinformation / Hallucination** | Model generates factually incorrect statements presented with high confidence. | - Explicit RAG grounding with source document citations (`[Source: filename, Chunk N]`).<br>- Emotion-aware prompt conditioning instructs model to acknowledge knowledge limits. | [`src/backend/rag/retriever.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/rag/retriever.py)<br>[`src/backend/llm/prompts.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/llm/prompts.py) |
| **LLM10: Unbounded Consumption (DoS)** | Overwhelming model inference with massive input contexts or concurrent streaming sessions. | - 30-second audio duration cap.<br>- 20 utterances/minute rate limiting per session.<br>- `GPUConcurrencyLimiter` and circuit breaker protecting GPU compute and VRAM. | [`src/backend/security/rate_limiter.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/security/rate_limiter.py)<br>[`src/backend/resilience/gpu_limiter.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/resilience/gpu_limiter.py)<br>[`src/backend/resilience/circuit_breaker.py`](file:///d:/Capstone%20Project/NewSenseVoice/src/backend/resilience/circuit_breaker.py) |
